🧮สรุปปริมาณคาร์บอนฟุตพริ้นท์ตามประเภท (Setcarbon) — tCO₂e

แบ่งประเภทข้อมูลตาม Setcarbon · คำนวณ kgCO₂e ÷ 1,000 = tCO₂e · ประเภท 1 = น้ำมัน · ประเภท 2 = ไฟฟ้า · ประเภท 3 = น้ำประปา + ขยะทั่วไป + เศษอาหาร + อันตราย + อิเล็กทรอนิกส์ · อื่นๆ = รีไซเคิล + Ewast+

📱การจัดการ QR code บันทึกปริมาณขยะสำนักงาน

QR code สำหรับให้พนักงานสแกนเพื่อเปิดหน้าบันทึกปริมาณขยะ: เข้าสู่ระบบ → เลือกอาคาร → เลือกชั้น → กรอกน้ำหนักแยกชนิด → ส่ง (เชื่อมกับ Google Sheets) กดบันทึก/พิมพ์ QR ไปใช้ได้เลย

🔗การเชื่อมต่อ Google Sheets

เชื่อมต่อฐานข้อมูลกลางผ่าน Google Apps Script เพื่อให้ทุกเครื่องเห็นข้อมูลร่วมกันและกันข้อมูลหาย (ถ้าไม่เชื่อมต่อ ระบบจะบันทึกในเครื่องแบบ Local)

ℹ️ ต้องนำสคริปต์ Code.gs ไปวางใน Apps Script ของ Google Sheet ก่อน (ดูไฟล์คู่มือที่แนบมา) ระบบจะสร้างชีตที่จำเป็นให้อัตโนมัติ: Records, Buildings, EmissionFactors, Settings, Users, Logs

🌍ค่า Emission Factor — แบ่งตาม Setcarbon (ประเภท 1-3 และอื่นๆ) — แก้ไขได้

ค่าสัมประสิทธิ์การปล่อยก๊าซเรือนกระจกที่ใช้คำนวณคาร์บอนทุกหน้า · ประเภท 1 = น้ำมัน (kgCO₂e/ลิตร) · ประเภท 2 = ไฟฟ้า (kgCO₂e/kWh) · ประเภท 3 = น้ำประปา (kgCO₂e/m³) + ขยะกำจัด (kgCO₂e/kg) · อื่นๆ = รีไซเคิล + Ewast+ · แก้ไขค่าและระบุที่มาได้
